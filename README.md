# Customer-Churn-Prediction-API
Machine Learning API for predicting customer churn

## Dataset Chosen

**Dataset:** Telco Customer Churn Dataset

## Problem Chosen

The goal is to predict whether a customer will churn or stay.

## Problem Type

Binary Classification

## Model Chosen

Logistic Regression

## Input / Output Contract

The API will accept customer information such as tenure, contract type, monthly charges, and service details as input.

The API will return whether the customer is likely to churn or stay.

## Project Flow

Request → Validation → Machine Learning Model → Prediction Response
