# Customer Churn Prediction API

A Machine Learning based customer churn prediction project that integrates SQL data preparation, Python data analysis, machine learning, model explainability, input validation, reusable ML pipeline, and business-oriented retention recommendations.

## 📌 Project Overview

Customer churn refers to customers who stop using or cancel a service.

The objective of this project is to analyze customer behavior, identify churn patterns, predict customers who are likely to churn, and provide retention strategy recommendations.

## 📊 Dataset

**Dataset:** Telco Customer Churn Dataset

- Total Customers: 7,043
- Problem Type: Binary Classification
- Target Variable: Churn

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook
- SQL Server / SSMS
- Power BI
- FastAPI
- Joblib
- GitHub

## 🤖 Machine Learning Model

**Model:** Logistic Regression

The model is used to predict whether a customer is likely to churn or stay based on customer attributes and service information.
